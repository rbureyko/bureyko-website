# Bureyko Mortgage Partners website: standing rules

- **Business name:** always "Bureyko Mortgage Partners".
- **Titles:** Sherri and Robin Bureyko are both **Mortgage Professionals**. Always call them that. Never call them mortgage brokers. General explanations of what "a mortgage broker" does in blog posts may stay.
- **Brand colours:** blue #306AB4, dark text #193C66, orange #F1A34B, light blue #9FC0D2, white. Dark text on orange buttons. No grey accents.
- **Blog posts** arrive from Sherri as final text. Don't rewrite them; handle layout, links (`src/posts/links.json`) and covers (`node covers.mjs`).
- Pages and wording live in `src/content.mjs`; styles in `src/assets/styles.css`. Pushing to `main` publishes the site via GitHub Pages.
- **Brokerage line:** use only this wording, exactly, everywhere (it lives in `SITE.brokerageStatement` in `src/content.mjs`): "Bureyko Mortgage Partners, powered by Mortgage Architects, is a member of the publicly traded DLCG group of companies. Together, our networks originate more mortgages in Canada than any individual bank, trust company, or credit union."
- **Compliance:** the For REALTORS® page and the realtor one-pager were cleared by Mortgage Architects compliance in October 2026.
- **Break Up With Renting** (free first-time buyer program): pages in `src/buwr.mjs`; dates, Zoom, venue, videos and downloads in `src/buwr/content.json`; Session 1 tools in `src/buwr/tools/`. The members area (`/break-up-with-renting/members/`) is encrypted at build time with the `MEMBERS_PASSWORD` GitHub Actions secret (never in code); without the secret it publishes as "opening soon". Members log in with the shared password on the public page's "Member login" panel or `/break-up-with-renting/login` (exact case, stays logged in 90 days on that device; changing the password logs everyone out). The site stays on GitHub Pages, so this is all done in the browser (`src/protect.mjs`); there's no login server. The scorecard, budget and debt tools each have a "Send to Robin" panel (Sherri's design; keep its markup and copy). It posts to the "Send to Robin" Cloudflare Worker (`worker/`, URL in `sendToRobinUrl`), which sends the two approved emails (Sherri's "Send to Robin: Email Templates") through Resend from robin@bureykomortgages.ca; budget sends totals only. The Worker publishes from `.github/workflows/worker.yml` using the GitHub secrets `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` and `RESEND_API_KEY`. It stores nothing and logs only the tool, time and whether it sent. The same Worker sends the automatic replies for the Founding Crew, First-Time Home Buyer Guide and Mortgage Renewal Check-Up Jotforms (wording in `worker/src/replies.js`): each form's Jotform webhook calls `/jotform/<JOTFORM_HOOK_KEY>`; Jotform still sends Robin's notifications. The website itself stays on GitHub Pages. Program pages use real photos only, no illustrations. Never invent dates, links, testimonials or video links.
